# Evaluation independence boundary (2026-11-16)

Public cases and the new regression fixtures are synthetic. The numeric workspace
uses FakeDeterministicAdapter. GoldRecord fields for annotator/adjudicator and
hashes are not proof of independent real-world review. No independent business
gold collection was obtained here. These results must not be described as blind,
expert-certified or enterprise acceptance evidence.

Paired comparison previously validated connected metadata but discarded its
result, grouping CI samples by scenario_family alone. Different scenario labels
sharing documents, sources, products, contracts, incidents or derivations could
inflate the independent cluster count. It now uses registered connected components
including transitive relations. One component gives no CI (INSUFFICIENT_CLUSTERS).
Point accuracy and critical-regression gates stay unchanged. Component independence
is explicitly an assumption, not independently verified fact.

Before a business-quality claim, obtain authorized source material, freeze a
private rubric and gold set before model access, record genuine independent
review/adjudication, separate connected families across splits and preserve actual
evaluator and source hashes. Never invent reviewer IDs or labels. Private gold
must not enter model inputs/public artifacts; publish only approved aggregates.

Restored-authorization checks remain synthetic software evidence. Approval seals
and current eligibility are separate; stale backups quarantine all identities;
offline owner-reviewed activation is allowlisted and transactional. They do not
replace real current revocation records or an identity provider. Real PostgreSQL17
and production role isolation remain unrun.
